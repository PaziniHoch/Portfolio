#Olá, este é meu Portfólio Online.

O projeto tem como objetivo apresentar um pouco da minha trajetória de aprendizado, meus projetos e minhas habilidades em desenvolvimento web, além de servir como um espaço que poderá ser atualizado e evoluído conforme adquiro novos conhecimentos.

## Acesse o projeto

**Portfólio online:**  
[https://pazinihoch.github.io/Portfolio/](https://pazinihoch.github.io/Portfolio/)

## Sobre 
Este projeto foi desenvolvido inicialmente como um desafio do Instituto Eldorado, utilizando **HTML, CSS e JavaScript** como tecnologias disponíveis para o desenvolvimento.

A primeira versão foi construída com foco nos fundamentos de desenvolvimento Front-End, explorando estruturação de páginas, estilização, organização visual e algumas interações.

O portfólio ainda está em desenvolvimento e será aprimorado continuamente conforme novos conhecimentos e projetos forem adquiridos.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivos futuros

- Adicionar novos projetos ao portfólio;
