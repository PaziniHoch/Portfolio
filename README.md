# Olá, este é meu Portfólio Online.

O projeto tem como objetivo apresentar um pouco da minha trajetória de aprendizado e das minhas habilidades em desenvolvimento web, além de servir como um espaço para acompanhar minha evolução conforme adquiro novos conhecimentos.

## Acesse o projeto

[https://pazinihoch.github.io/Portfolio/](https://pazinihoch.github.io/Portfolio/)

## Sobre 
Desenvolvido inicialmente como um desafio do Instituto Eldorado, utilizando **HTML, CSS e JavaScript** como tecnologias disponíveis para o desenvolvimento.

A primeira versão foi construída com foco nos fundamentos de desenvolvimento Front-End, explorando estruturação de páginas, estilização, organização visual e algumas interações.

O portfólio ainda está em desenvolvimento e será aprimorado continuamente conforme novos conhecimentos e projetos forem adquiridos.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivos futuros

- Adicionar novos projetos ao portfólio;
- Implementar mais interações utilizando JavaScript;
- Melhorar a responsividade e a experiência em diferentes dispositivos;
- Aprimorar o design e a organização do código;
- Explorar novas tecnologias e ferramentas de Front-End;
- Manter o portfólio atualizado conforme minha evolução profissional.
